# Задача 1. Two sum

## Корректность решения

Для поиска пары используется словарь, в котором сохраняются уже просмотренные элементы массива и их индексы.

Для каждого элемента проверяется, встречалось ли ранее число, которое в сумме с текущим даёт k.

По условию задачи подходящая пара существует ровно одна, поэтому как только она найдена, функция сразу возвращает два индекса.

Решение корректно работает с повторяющимися значениями, отрицательными числами и нулями.

## Идея решения

Пусть текущий элемент массива равен num.

Чтобы получить сумму k, второе число должно быть равно:

k - num

Во время прохода по массиву уже просмотренные числа сохраняются в словаре seen в формате:

значение -> индекс

Для каждого нового элемента вычисляется необходимое число need = k - num.

Если need уже находится в seen, значит нужная пара найдена. Возвращается индекс из словаря и индекс текущего элемента.

Если нужного числа ещё нет, текущий элемент добавляется в словарь.

Текущий элемент добавляется только после проверки. Это важно, чтобы один и тот же элемент массива не мог использоваться дважды.

Так как массив просматривается слева направо, найденный ранее индекс всегда меньше текущего, поэтому индексы сразу возвращаются в порядке возрастания.

## Оценка сложности

Пусть n это количество элементов в массиве arr.

Время O(n).

Каждый элемент массива рассматривается один раз. Проверка наличия элемента в словаре в среднем выполняется за O(1).

Память O(n).

В худшем случае в словаре сохраняются почти все элементы массива.

## Визуализация

Пусть arr = [1, 3, 4, 10], k = 7.

Первый элемент 1. Для него нужно число 6.

6 в словаре нет, поэтому сохраняем 1 с индексом 0.

seen = {1: 0}

Следующий элемент 3. Для него нужно число 4.

4 в словаре нет, поэтому сохраняем 3 с индексом 1.

seen = {1: 0, 3: 1}

Следующий элемент 4. Для него нужно число 3.

3 уже есть в словаре с индексом 1.

Текущий индекс равен 2.

Итоговый результат: 1 2.

## Тесты

Проверяется пример из условия, случай с одинаковыми значениями, отрицательные числа, нули, пара в начале массива, пара в конце массива и случай с элементами разного знака.

Также отдельно проверяется случай arr = [5, 5, 1, 4], k = 10, чтобы убедиться, что решение корректно работает с двумя одинаковыми значениями и не использует один элемент дважды.
