# Adaptive Hash Table

## Идея
Коллизии разрешаются методом цепочек.
Часто запрашиваемые элементы постепенно перемещаются
к началу цепочки с помощью transpose heuristic.

## Resize
Таблица увеличивается при load factor > 0.75
или слишком длинной цепочке коллизий.

## Сложность
insert — O(1) в среднем
get — O(1) в среднем
remove — O(1) в среднем
resize — O(n)

В худшем случае операции могут занимать O(n).
