# Задача 2. Anagrams

## Корректность решения

Для группировки анаграмм используется словарь.

Для каждого слова создаётся ключ из его букв, отсортированных в алфавитном порядке.

Все анаграммы состоят из одинаковых букв в одинаковом количестве, поэтому после сортировки их ключи совпадают.

Например:

eat -> aet  
tea -> aet  
ate -> aet

Все три слова получают одинаковый ключ и добавляются в одну группу.

Слова, которые не являются анаграммами, получают разные ключи и попадают в разные группы.

Решение корректно работает с пустым списком, одним словом, повторяющимися словами, пустыми строками, словами разной длины и словами с повторяющимися буквами.

## Идея решения

Создаётся словарь groups.

Ключом словаря является отсортированная версия слова, а значением список всех слов с таким ключом.

Для каждого слова выполняется сортировка его символов.

Например:

eat -> aet  
tea -> aet  
tan -> ant  
ate -> aet  
nat -> ant  
bat -> abt

После обработки всех слов словарь будет выглядеть примерно так:

aet -> [eat, tea, ate]

ant -> [tan, nat]

abt -> [bat]

После этого остаётся вернуть все значения словаря.

В результате получаем группы слов, каждая из которых содержит только анаграммы.

## Оценка сложности

Пусть n это количество слов, а m это средняя длина одного слова.

Сортировка одного слова занимает O(m log m).

Она выполняется для каждого из n слов.

Поэтому общая временная сложность:

O(n * m log m).

Память O(n * m).

Все исходные слова сохраняются в группах. Также для каждого слова временно создаётся отсортированный ключ.

## Визуализация

Пусть:

strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

Первое слово:

eat -> aet

Создаётся группа:

aet -> [eat]

Следующее слово:

tea -> aet

Такой ключ уже существует, поэтому слово добавляется в существующую группу:

aet -> [eat, tea]

Следующее слово:

tan -> ant

Создаётся новая группа:

ant -> [tan]

Для слова ate снова получается ключ aet:

aet -> [eat, tea, ate]

Для nat получается ant:

ant -> [tan, nat]

Для bat получается новый ключ abt:

abt -> [bat]

После обработки всех слов получаем три группы:

[eat, tea, ate]

[tan, nat]

[bat]

Порядок групп и порядок слов внутри групп не влияет на корректность результата.

## Тесты

Тестами проверяется пример из условия, пустой список, список из одного слова, случай когда все слова являются анаграммами и случай когда ни одно слово не имеет анаграммы.

Также проверяются одинаковые слова, пустые строки, слова с повторяющимися буквами и слова разной длины.

Отдельный тест содержит большое количество слов и проверяет работу функции на нескольких крупных группах анаграмм.

Так как порядок групп в результате не является существенным, перед сравнением результат тестов приводится к единому виду. Слова внутри каждой группы сортируются, после чего сортируются сами группы.
