# Задача 2. Максимальная чётная сумма

## Идея решения

Если сумма массива чётная — возвращаем её.

Если нечётная — удаляем минимальное нечётное число, чтобы потерять как можно меньше.

## Оценка сложности

Время: O(N²)

min() и remove() работают за O(N), цикл может выполниться O(N) раз.
Память: O(N)
Создаётся копия массива.

## Визуализация

nums = [2, 5, 7, 13, 14]
Сумма = 41.

В копии удаляем минимальное чётное 2.

Минимальное нечётное теперь 5.

Удаляем 5 из исходного массива:

[2, 7, 13, 14]

Ответ: 36.

## Выбор алгоритма

Идея состояла в том, чтобы при нечётной сумме удалить минимальное нечётное число и тем самым получить максимальную возможную чётную сумму.
