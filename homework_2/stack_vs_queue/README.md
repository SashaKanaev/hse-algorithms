# Задача 1. Стек и очередь на основе связных списков

## Идея решения

Стек и очередь реализованы на основе односвязного списка.

Каждый элемент хранится в объекте Node. В нём находятся значение элемента и ссылка next на следующий узел.

В стеке используется принцип LIFO. Последний добавленный элемент удаляется первым.

Для стека хранится ссылка head на верхний элемент. При push новый узел становится новым head. При pop head переносится на следующий узел.

В очереди используется принцип FIFO. Первый добавленный элемент удаляется первым.

Для очереди хранятся head и tail. Новый элемент добавляется через tail. Удаление происходит через head.

Также в обеих структурах хранится _size, который изменяется при добавлении и удалении элементов.

## Корректность решения

Стек работает по принципу LIFO, так как добавление и удаление происходят через head.

Очередь работает по принципу FIFO, так как новые элементы добавляются в конец через tail, а удаляются из начала через head.

Если очередь становится пустой после dequeue, head и tail становятся None.

Для пустого стека pop и peek вызывают IndexError. Для пустой очереди dequeue и peek также вызывают IndexError.

Размер структуры хранится в _size и всегда изменяется вместе с количеством элементов.

## Оценка сложности

Для стека push, pop, peek, is_empty и получение размера работают за O(1).

Все операции выполняются через head, поэтому проход по списку не требуется.

Для очереди enqueue, dequeue, peek, is_empty и получение размера также работают за O(1).

Добавление выполняется через tail, удаление через head, поэтому проход по списку также не нужен.

Память O(n).

Для каждого элемента создаётся один объект Node, поэтому используемая память зависит от количества элементов.

## Визуализация

Для стека последовательно выполняются push(1), push(2), push(3).

После добавлений стек содержит 1, 2, 3, при этом верхним элементом является 3.

Первый pop возвращает 3. Следующий pop возвращает 2. Последний pop возвращает 1.

Получается порядок 3, 2, 1, что соответствует LIFO.

Для очереди последовательно выполняются enqueue(1), enqueue(2), enqueue(3).

После добавлений первым элементом является 1, последним 3.

Первый dequeue возвращает 1. Следующий dequeue возвращает 2. Последний dequeue возвращает 3.

Получается порядок 1, 2, 3, что соответствует FIFO.

## Тесты

Для стека проверяется обычная работа LIFO, работа peek, корректность размера, работа с пустым стеком и добавление новых элементов после pop.

Для очереди проверяется обычная работа FIFO, работа peek, корректность размера, работа с пустой очередью и повторное использование после полного удаления элементов.

Отдельно проверяется случай, когда после удаления последнего элемента очереди head и tail становятся None.
