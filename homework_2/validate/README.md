# Задача 2. Validate

## Корректность решения

Решение последовательно обрабатывает все элементы pushed и моделирует работу обычного стека.

Каждый элемент сначала добавляется в стек. После этого проверяется, совпадает ли верхний элемент стека с текущим элементом popped. Если совпадает, элемент удаляется, проверка продолжается для следующего элемента popped.

Если после обработки всего pushed стек полностью опустел, последовательность popped могла быть получена корректной последовательностью операций пуш и поп.

## Идея решения

Изначально рассматривал задачу как проверку двух последовательностей, потом понял что здесь важно смоделировать работу стека.

Элементы можно добавлять только в том порядке, в котором они находятся в pushed. Удалять можно только верхний элемент стека.

Поэтому каждый элемент pushed последовательно добавляется в stack. После каждого добавления проверяется верхушка stack. Если она совпадает с текущим элементом popped, выполняется pop и указатель i переходит к следующему элементу popped.

Используется while, а не if, потому что после одного удаления сверху может сразу оказаться следующий нужный элемент. В таком случае можно выполнить несколько pop подряд.

Если нужный элемент находится внутри стека, но сверху лежит другой элемент, достать его нельзя. Именно в таком случае последовательность оказывается невозможной.

## Оценка сложности

Время: O(n)

Каждый элемент pushed ровно один раз добавляется в стек. Каждый элемент может быть удалён из него не более одного раза.

Несмотря на то, что while находится внутри for, это не даёт O(n²), потому что суммарное количество операций pop за всю работу алгоритма не превышает n.

Получается максимум n добавлений и n удалений, поэтому итоговая сложность O(n).

Память: O(n)

В худшем случае сначала потребуется положить в стек все элементы pushed. Например, если popped содержит элементы в полностью обратном порядке.

Поэтому размер дополнительного стека в худшем случае равен n.

## Визуализация

Пусть:

pushed = [1, 2, 3, 4]

popped = [2, 4, 3, 1]

Сначала добавляется 1.

stack = [1]

Первым нужно получить 2, поэтому удалять 1 нельзя.

Добавляется 2.

stack = [1, 2]

Верхний элемент равен 2, поэтому выполняется pop.

stack = [1]

Следующим нужно получить 4.

Добавляется 3.

stack = [1, 3]

Верхний элемент не равен 4, поэтому 3 остаётся в стеке.

Добавляется 4.

stack = [1, 3, 4]

4 совпадает с текущим элементом popped и удаляется.

После этого верхним становится 3. Следующим элементом popped также является 3, поэтому он тоже сразу удаляется.

После удаления 3 верхним становится 1. Последним элементом popped является 1, поэтому он также удаляется.

В конце:

stack = []

Была получена последовательность [2, 4, 3, 1], поэтому результат True.

## Тесты

Тесты проверяют примеры из условия, одинаковый порядок pushed и popped, полностью обратный порядок, несколько нетривиальных допустимых и недопустимых последовательностей.

Также отдельно проверяется минимальный случай из одного элемента и максимальный размер последовательности из 100000 элементов.

## Идея

Главный момент задачи в том, что элемент нельзя временно достать из стека, чтобы получить элемент под ним, а затем положить обратно. Каждый pop сразу становится следующим элементом последовательности popped.

Поэтому достаточно последовательно добавлять элементы pushed и каждый раз удалять все элементы сверху, которые уже совпадают с ожидаемым порядком popped.
