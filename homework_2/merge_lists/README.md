# Задача 3. Merge lists

## Корректность решения

Реализованы два способа объединения двух отсортированных односвязных списков, с использованием фиктивного элемента и без него.

В обоих вариантах новые узлы для результата не создаются. Итоговый список формируется из узлов исходных списков.

Решение корректно работает с пустыми списками, списками разной длины, одинаковыми и отрицательными значениями.

## Идея решения

Оба списка уже отсортированы, поэтому на каждом шаге достаточно сравнивать первые необработанные элементы list1 и list2.

Если значение в list1 меньше или равно значению в list2, в результирующий список добавляется узел из list1, после чего list1 перемещается на следующий узел.

Если значение в list2 меньше, добавляется узел из list2 и list2 также перемещается дальше.

После добавления узла current перемещается на последний элемент результирующего списка.

Когда один из списков заканчивается, остаток второго списка можно добавить целиком, так как он уже отсортирован.

В варианте с фиктивным элементом сначала создаётся dummy. Он используется как временное начало списка. Это позволяет не обрабатывать первый элемент отдельно. В конце возвращается dummy.next, то есть первый настоящий элемент результата.

В варианте без фиктивного элемента первый узел результата определяется отдельно сравнением первых элементов list1 и list2. Он сохраняется в head. После этого дальнейшее слияние выполняется тем же способом.

## Оценка сложности

Пусть n это количество элементов в list1, m это количество элементов в list2.

Время O(n + m).

Каждый узел обоих списков рассматривается не более одного раза.

Память O(1).

Дополнительные списки и массивы не создаются. Используется только постоянное количество ссылок на узлы. В варианте с dummy создаётся один дополнительный узел, поэтому асимптотика памяти не меняется.

## Визуализация

Пусть list1 = [1, 2, 4], list2 = [1, 3, 4].

Сравниваются первые элементы, 1 и 1. Берётся 1 из list1. Результат [1].

Теперь сравниваются 2 и 1. Берётся 1 из list2. Результат [1, 1].

Сравниваются 2 и 3. Берётся 2 из list1. Результат [1, 1, 2].

Сравниваются 4 и 3. Берётся 3 из list2. Результат [1, 1, 2, 3].

Сравниваются 4 и 4. Берётся 4 из list1. Результат [1, 1, 2, 3, 4].

После этого list1 заканчивается. Оставшийся элемент list2 добавляется в конец.

Итоговый результат [1, 1, 2, 3, 4, 4].

## Тесты

Для обеих реализаций используется одинаковый набор тестов.

Проверяется пример из условия, два пустых списка, случай когда пуст только один список, списки из одного элемента, списки разной длины, одинаковые значения, отрицательные значения, случай когда все элементы одного списка меньше элементов другого и более сложное чередование значений.

Также отдельно проверяется, что результирующий список действительно состоит из узлов исходных списков, а не из заново созданных узлов.
