# Iterative

## Корректность и идея

Реализовал обе сортировки без рекурсии. Возвращают отсортированную копию входного списка.

- `merge_sort_iterative`: сначала сливает соседние группы длины 1, затем 2, 4, 8 и так далее. Использует второй буфер.
- `quick_sort_iterative`: разбивает массив относительно последнего опорного, а вместо рекурсивных вызовов хранит диапазоны в стеке. Меньший диапазон обрабатывает сразу, больший откладывает.

## Сложность

| Алгоритм | Время | Дополнительная память |
|---|---|---|
| Итеративный merge sort | O(n log n) | O(n) для двух списков |
| Итеративный quick sort | O(n log n) в среднем, O(n²) в худшем | O(log n) для стека, плюс O(n) для копии |

В merge sort выполняется O(log n) проходов по n элементам. В quicksort время зависит от сбалансированности разбиений. Обработка меньшей части сразу ограничивает размер явного стека O(log n).

## Визуализация

Пример: `[7, 2, 6, 1, 5, 3]`.

```text
Merge (ширина группы):
1: [2, 7] [1, 6] [3, 5]
2: [1, 2, 6, 7] [3, 5]
4: [1, 2, 3, 5, 6, 7]

Quick:
[7, 2, 6, 1, 5, 3], pivot=3
[2, 1] | 3 | [7, 5, 6]
[1, 2] | 3 | [5, 6, 7]
[1, 2, 3, 5, 6, 7]
```

## Тесты

Проверил пустой массив, один элемент, повторы, отрицательные числа, случайные списки и длины, не равные степени двойки. Для проверки отсутствия рекурсии quicksort сортирует 1600 уже упорядоченных элементов.
