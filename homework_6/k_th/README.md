# K-th

## Корректность и идея

`find_kth_largest(nums, k)` находит k-й **по величине** элемент, учитывая повторяющиеся значения. Например, для `[5, 5, 3]` второй по величине — `5`.

Использовал **quickselect** без полной сортировки и без кучи. Индекс нужного элемента в порядке возрастания равен `n - k`. На каждом шаге выбирается опорный элемент из середины текущего диапазона и выполняется трёхстороннее разбиение: меньше, равно, больше опорного. Продолжаем поиск только в части с целевым индексом. Входной список не меняется; некорректный `k` вызывает `ValueError`.

## Сложность

Среднее время — **O(n)**: после линейного разбиения обрабатывается только одна часть. Худшее время — **O(n²)** при неудачных опорных элементах. Память — **O(n)** на копию массива и **O(1)** сверх неё; рекурсии нет.

## Визуализация

`nums = [3, 2, 1, 5, 6, 4]`, `k = 2`, целевой индекс `6 - 2 = 4`.

```text
pivot=1: [1, 2, 5, 6, 4, 3] -> ищем справа, индексы 1..5
pivot=6: [1, 2, 5, 4, 3, 6] -> ищем слева, индексы 1..4
pivot=5: [1, 2, 4, 3, 5, 6] -> индекс 4 в группе равных 5
Ответ: 5
```

## Тесты

Проверил оба примера из условия, повторы, отрицательные числа, `k=1`, `k=n`, одиночный массив, случайные данные и неправильные `k` (включая пустой список). В тестах результат сравнивается с `sorted(nums)[-k]`; **в самом решении сортировки нет**.
